# Fetal Health Prediction Using Machine Learning

## 📖 Project Overview

This project aims to predict the health condition of a fetus using Machine Learning techniques. The model classifies fetal health into different categories based on cardiotocography (CTG) data, helping in early identification of potential fetal health issues.

---

## 🎯 Objective

To build a machine learning model that accurately predicts fetal health using the provided dataset and compares the performance of different classification algorithms.
